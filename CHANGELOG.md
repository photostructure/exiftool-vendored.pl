# Changelog

This package vendors [ExifTool](https://exiftool.org/). The major.minor of the
package version is the vendored ExifTool version, and the patch number counts
releases of that ExifTool: ExifTool 13.61 ships as 13.61.0, and a package-only
change to it ships as 13.61.1. SemVer drops ExifTool's zero-padded minor, so
ExifTool 14.05 ships as 14.5.0.

Releases before 13.61.0 are described on the
[GitHub Releases](https://github.com/photostructure/exiftool-vendored.pl/releases) page.
